# 2SOUL - Премиальный интернет-магазин

Полнофункциональный интернет-магазин на Flask с интеграцией YooKassa, админ-панелью и современным дизайном.

## ✨ Особенности

- 🛍️ Каталог товаров с фильтрацией и поиском
- 🛒 Корзина покупок с управлением количеством
- 💳 Интеграция с YooKassa для принятия платежей
- 👨‍💼 Защищённая админ-панель с управлением заказами и товарами
- 📱 Адаптивный дизайн для мобильных устройств
- ✨ Премиальный современный стиль
- 🔒 Безопасная авторизация администратора

## 🚀 Быстрый старт

### 1. Клонирование и подготовка

```bash
# Клонирование репозитория
git clone <url-репозитория>
cd 2soul-shop

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
